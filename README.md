# Anjali — Raksha Bandhan Digital Gift ❤️

A premium, multi-page React + Three.js + Framer Motion surprise website using the **real uploaded photos and videos**.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite gives you.

## Build

```bash
npm run build
npm run preview
```

## Add background music

Put your MP3 at:

`public/music.mp3`

The floating music button will play it only after the user interacts with the site.

## Media

All uploaded personal media is already inside `public/media/`:

- `memory-01.jpg` … `memory-08.jpg`
- `video-01.mp4` … `video-03.mp4`
- generated lightweight video posters in `public/media/posters/`

No stock photos or AI-generated people are used.

## GitHub Pages

For GitHub Pages, set the Vite `base` option in `vite.config.js` to your repository name, e.g. `base: '/anjali-raksha-bandhan/'`, then build and deploy the `dist` folder using your preferred GitHub Pages workflow.
